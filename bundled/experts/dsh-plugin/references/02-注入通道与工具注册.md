# 注入通道与工具注册

## inject 与 ctx.get 的区别

- `export const inject = ['a','b']`：**必需**服务。缺一个，插件停在 pending，面板里显示「未生效」。
- `ctx.get('c')`：**可选**服务。拿不到返回 `undefined`，要自己判空。

把可选服务写进 `inject` 是最常见的装死原因：宿主没装那个服务，你的插件就一直 pending。

```js
export const inject = ['tools']
export function apply(ctx) {
  const presets = ctx.get('agentPresets')   // 可选，拿不到就算了
  if (presets) { /* ... */ }
}
```

## 注册一个工具

```js
ctx.tools.register(
  'my_lookup',
  {
    description: '一句话说清什么时候该调用',
    parameters: { type: 'object', properties: { query: { type: 'string' } }, required: ['query'] },
  },
  async (args) => ({ content: [{ type: 'text', text: '结果' }] })
)
```

三条经验：

1. `description` 决定模型什么时候调用它，比参数名重要。
2. 参数对象可能被冻结，别在 handler 里改 `args.xxx`，用局部变量。
3. 返回长文本会给上下文加压，能短则短，详情让模型再取一次。

## 注册技能

技能 provider 必须返回带 `name` 的对象：

```js
{ name: 'my-skill', description: '…', content: 'SKILL.md 正文' }
```

写成 `id` 会让宿主拿到 `undefined`，直接崩，并可能触发安全模式清空已装插件。

## 面板侧

面板组件用 React（宿主注入），入口字段：
- `sidebar.panellist`：`{ id, title, order, icon }`；
- `main`：`{ component: Panel }`。

面板里读数据走自己的 HTTP 路由（`ctx.webServer`），不要直接读宿主的内部状态。
