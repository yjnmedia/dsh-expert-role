# 三表登记与检索

## 为什么要三处

- **文件**：正文本身。
- **`references/index.md`**：给人看的目录，翻资料时先看它。
- **`manifest.json`**：给检索看的索引。

只登记 index 是最常见的错：人翻得到，模型搜不到。反过来只登记 manifest，人翻目录时会以为资料丢了。

## 检索是怎么算的

1. 把「标题 + 摘要 + 正文前 1200 字」拼成一段文本，每份资料一行向量。
2. 问题也变成向量，算余弦相似度。
3. 先按大类收窄候选（软过滤：与最高分相差很小的几个大类都保留），再在候选里精排。
4. 取前 3–5 份，附路径与分数。

没有本地向量模型时，退化成关键词匹配（字符二元组重合度），精度低一些但能用。

## 阈值

- 第一名低于 0.5：多半是库里没有，回答里要说「不确定」。
- 前两名分差小于 0.01：两份都像，别硬选一份。

这两个数是经验值，换模型或换资料风格都要重新校准。

## 写摘要的三条

- 一句话说结论，不要写「本文介绍了……」。
- 带上可数的数字（字号、毫秒、份数），检索与人都更好用。
- 别把标题原样复制成摘要。
